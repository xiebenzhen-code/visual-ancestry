## 2. 数据规则

- **准入**（与检索同契约，独立实现不 import）：`status === "success" && visualIntent.source !== "empty"/"example"`
- **metadata 永不参与**：聚合只读 `visualIntent`——title/tags 里的「孤独夜晚城市」不会污染统计（QA Case 3 断言）
- **聚合 = 计数**：每个指标 = 池内真实占比（`{count, ratio}`），零权重设计
- **空池除零**：ratio 返回 0.00 而非 NaN（诚实，QA Case 4 断言）

## 4. Confidence（固定阈值，防伪造审美）

| 样本 | level | 语气 |
|------|-------|------|
| 0 | `empty` | 「还没有可分析的视觉资产。」 |
| 1–19 | `observation` | 「当前收藏还少，以下是初步观察。」 |
| 20–50 | `tendency` | 「你的收藏开始显现稳定的倾向。」 |
| 50+ | `pattern` | 「你的收藏已经形成清晰的视觉模式。」 |

`basis` 强制展示「based on N visual memories」——19 张时永远不说「你的审美就是」。

## 7. 产品限制（诚实清单）

1. **画像只是计数**：不证明因果、不预测喜好、不是审美评价——页面上没有「你应该」
2. **emotion 层不可用**（冻结 Vision 层产出稀疏）：narrative 组靠结构字段（humanRelation/socialDistance/arousal/melancholy）承载，不含情绪词
3. **composition/geometry 不可用**：compositionProfile 用 subjectPosition/cameraDistance/motion 替代承载
4. **池同质化时区分度有限**：大量同类素材会让 ratio 虚高（无去重/去相似机制——属 V2 后议题）
5. **单用户本地档案**：无账号、无云同步；浏览行为（#eye）永不混入
6. confidence 在 20/50 边界处的语气切换是**样本量函数**，与内容质量无关
