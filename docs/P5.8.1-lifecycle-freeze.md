## 冻结物：Personal Memory Lifecycle Contract V1

1. **Archive 契约**（`docs/P5.8.1-archive-contract-v1.md`）：
   `{format:"visual-archive", version:1, exportedAt, memoryCount, memories[]}` —— memories 原样携带（含 userData.thumbnail），format/version/memoryCount 三重校验，坏条目跳过并报告
2. **Clear 边界**：`clearPersonalMemory()` 只删 Personal Memory（`visual-memory:v1` / QA `memories.json`）；artwork cache、#eye 画像（utils/profile.js）、artService 缓存、QA fixtures 永不触碰（QA 断言固定）
3. **Import 语义**：merge（按 id upsert，archive 版本覆盖）/ replace（先 clear 后导入）；整体拒绝优先于部分导入
4. **图像事实声明**：Archive 含缩略图（420px JPEG data URL 或远程 URL），不含原图——原图从未被产品持久化（审计 §C）
