## C. 限制（主动同屏展示）

1. **Local-first**：数据只在本机浏览器/本地 store——无跨设备，换浏览器需手动导出/导入（特性即边界）。
2. **单用户**：无账号、无多用户隔离；一个浏览器一个档案。
3. **未云同步**：不做云服务；备份 = 导出 JSON（42 条实测 40.5KB）。
4. **100+ 待补验证**：机制性验证（阈值/漂移/锚定）在 62 唯一条目内完成；字面规模待 provider 配额恢复后补齐（路径已就绪）。
5. **规则式召回上限**：REASON_LABELS 人工枚举，长尾视觉关系靠 unmapped 诚实收集而非硬凑。
6. **单一 vision provider**：OpenAI 兼容端点，凭据仅在服务端进程。
7. **真人测试未执行**：P5.8.2/5.9.0 均为结构化模拟，真人清单就绪待跑。
