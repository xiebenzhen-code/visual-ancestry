## 1. 实现内容

**Assistant 薄层**（`src/services/memory/visualAssistant.js`，唯一新服务模块）——只组合冻结模块（visualProfile / retrieveVisualMemory / memoryRepository），零重实现 Vision/Retrieval/Profile，零 LLM 调用，零 Agent Loop。输入 `{task, query, context}`，三个任务：

1. **Understand My Taste**（`understandTaste`）— 调冻结 `buildVisualProfile()` → `{summary, evidence[], sampleSize, confidence, unavailable}`。语气纪律与冻结 presenter 同阈值（≥0.55 强句 / 0.40–0.55 弱句 / <0.40 不作主张）；空池诚实「样本不足」；evidence 全部带真实计数（如「低饱和 经常出现（26/34 · 76%）」）。
2. **Find My References**（`findReference`）— 规则式 NL→VisualQuery 映射（关键词→schema 真实枚举，未映射词诚实收集进 `unmapped`）→ 冻结检索 → 每条带 `reason/matchedFields/score`。零命中时的「个人倾向补全」：冻结 sharedReasons 标签表不含 humanRelation 等字段，纯这类查询被冻结过滤规则正确拒收（无可解释理由）——此时以用户自己的高频倾向（仅 reason-labeled 字段）补全查询并如实展示 `enrichedQuery`。
3. **Assist My Creation**（`creativeSupport`）— 场景意图 + 个人画像四组倾向（空间/构图/色彩/叙事）+ 检索真实历史参考 → Creative Brief。方向全部来自用户自己的收藏统计，输出明示「不是 AI 创作，最终决策在你」。

**UI**（`#memory/assistant`，`src/pages/memoryAssistant.js`）——**不是聊天窗口**：三张任务卡（我想找参考 / 我想了解我的视觉偏好 / 我正在创作），无对话线程、无 AI 生成区；结果复用冻结 `retrievalCard`（每条带「为什么匹配」）；`#memory` 新增第四 CTA。

**QA**：`qa/memory/assistant-test.mjs`（**29/29 PASS**，5 Case）+ `qa/memory/assistant-scenarios-test.mjs`（**13/13 PASS**，3 真实场景）。

## 4. Agent 边界（本阶段回答「它不是什么」）

| 禁止项 | 状态 |
|--------|------|
| AutoGPT / Agent Loop / 自主规划 | ❌ 无——编排 = 一次 switch + 组合调用 |
| 联网搜索 / 云 / 后端 | ❌ 无——纯本地组合层 |
| LLM 调用 / 生成式创作 | ❌ 无——NL 映射是规则表；Brief 是统计整理 |
| 替用户决策 / 自动导演方案 | ❌ 无——输出明示「最终决策在你」 |
| 审美等级 / 人格判断 / 「比别人高级」 | ❌ QA 断言禁词零出现 |
| 聊天窗口 | ❌ 三张任务卡，非对话 UI |
| 编造资产 / 幻觉 | ❌ Case 5：空池时全部任务诚实拒绝，零编造引用 |

## 5. 是否达到最初构想

**达到（轻量级）。** 最初构想的三层——「理解我的视觉偏好 / 寻找我的参考 / 辅助我的创作」——全部实现且被测试固定。系统从「等待用户搜索」变为「以三种创作任务主动组织个人记忆」：理解用统计、寻找用冻结检索、辅助用个人记忆的结构化整理。**它没有越界成为大 Agent**：没有循环、没有规划、没有生成——每一个输出都能追溯到冻结层的真实数据。

## 6. 验收三问

### Q1 — 它是不是一个轻量 Agent？

**是——按本阶段定义的轻量。** 不是聊天机器人（三任务卡 UI、无对话线程）；它**理解用户**（规则映射 + 个人画像统计）、**调用个人记忆**（冻结检索 + 真实参考证据）、**辅助创作**（Brief = 画像约束 + 历史参考）。同时它刻意**不是**自治 Agent：无循环、无规划、无 LLM、无联网、不决策。边界本身就是设计（Agent 边界表全部由 QA 断言固定）。

### Q2 — 是否需要后端？

**不需要。** 本阶段验证的是 Agent 价值，不是云产品：全部能力（存储/检索/画像/Assistant）在 local-first 架构内以纯前端 + 本地文件完成；NL 映射是本地规则表，无任何服务端依赖。这也与冻结边界一致（零云同步/零多用户）。

### Q3 — 是否进入产品化？

**Assistant 测试成立（42/42 断言全绿），P6 Backend Productization 的资格门开启**——若继续，下一阶段才考虑账号/云同步/数据库/移动端。但按 P5.5 决策与本阶段边界，当前项目状态为：**V2 Alpha + Assistant 层已可展示，是否投入 P6 由作品集反馈决定**（显式解锁单独立项，不默认启动）。

---

**诚实限制**：NL 映射是规则表（覆盖常用创作语汇，长尾表达会落入 unmapped 并明示——这是「不假装理解」的代价与设计）；创作辅助的方向来自既有收藏统计（收藏同质化时方向同质化，池无去重机制沿用 V2 已知限制）；Assistant 层未纳入 3 张 C 类资产（本阶段范围外）。
