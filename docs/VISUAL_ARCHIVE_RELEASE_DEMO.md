# Visual Archive — Release Demo Script（3 分钟 · 最终版）

> 场景：作品集评审 / 面试演示。真实操作录屏（`#memory` 本地环境，34 条真实资产池），无剪辑造假。
> 与 P5.4 内部版（`VISUAL_ARCHIVE_DEMO_SCRIPT.md`）的差异：对齐 Release 叙事——重点从「功能演示」转向「shared visual language 不是相似图片」与「系统记得你如何观看」。

---

## 0:00–0:30 问题：大量视觉参考无法形成个人语言

**画面**：一个塞满参考图的文件夹 / 普通相册应用，快速滚动，素材堆积。

**口播**：
> 创作者都会积累几百上千张视觉参考——电影截图、绘画、随手拍的构图。但存进文件夹的那一刻它们就死了：文件夹只记得文件，不记得视觉关系。一张宋代山水和一张 1927 年的电影远景，明明是同一种构图，文件夹永远把它们隔开。

**切画面**：浏览器打开 `#memory`（档案首页，34 条真实资产卡片墙）。

---

## 0:30–1:20 上传流程：Image → VisualIntent → Memory

**画面**：点「＋ 保存一段新素材」，拖入一张电影剧照（《大都会》布景）。

**过程展示**（等转译完成后点开详情页）：

```
Image（电影截图，零手动标签）
  ↓
VisualIntent（25 字段结构化视觉语言）
  ↓
Memory（本地持久化）
```

**口播**：
> 拖进来，我一个标签都不用打。AI 把它读成 25 个字段的结构化视觉语言——不是「一张建筑图」这种分类，而是构图关系：空间纵深、环境是否压过人物、光质、人际疏离。全部存在你自己的设备上。
>
> 如果分析失败，这张卡不会消失——它诚实地显示失败原因，一键重试。这个失败闭环是被 40 张真实上传压测验证过的。

---

## 1:20–2:10 核心展示：按感觉找回（shared visual language）

**画面**：点「按感觉寻找 →」，输入创作感觉：

```
孤独（孤立人物）
巨大空间（深空间 + 环境主导）
低饱和
```

**返回**（同榜混排，真实输出）：

```
Film Still          Painting
Die Nibelungen 1924  雾海漫游者
（10.3 印象·日出 · 9.5 Die Nibelungen · 9.5 雾海漫游者）
```

**口播**：
> 现在我说一个创作感觉：「孤独的人站在巨大环境里」。不用关键词，直接勾视觉特征——
>
> 看结果：一张 1927 年的德国电影布景和一张浪漫主义绘画出现在**同一个列表**里。重点不是「找相似图片」——是 **shared visual language**：它们被同一种视觉语言描述。每一条下面都写着为什么：环境压过人物、纵深很深、留白很大。不是黑箱推荐，是可解释的视觉证据。

**点开一条**：展示匹配理由 chips。

---

## 2:10–2:40 Profile：个人视觉趋势

**画面**：回到档案首页，点「我的视觉档案 →」。

**展示**（真实 34 资产池输出）：

```
Your visual archive tends toward:

deep space            23/34 · 68%
low saturation        26/34 · 76%
environment dominance 19/34 · 56%
```

**口播**：
> 收藏积累之后，系统从你的资产里统计你的视觉倾向——「based on 34 visual memories」。没有雷达图，没有评分，只有句子和真实计数。
>
> 同样重要的是它**不说**的部分：情绪词产出不足时，它明说「样本不足，无法呈现」。这个诚实是被测试固定住的，不是靠自觉。

---

## 2:40–3:00 总结

**画面**：回到档案首页全景 → 淡出到 Portfolio 页（`portfolio/visual-archive/index.html`）。

**口播**：
> 这就是 Visual Archive：图片进，视觉语言出，收藏变成可检索、可解释、可反思的个人视觉记忆。local-first，无账号，无云。
>
> **A system that remembers how you see.**
