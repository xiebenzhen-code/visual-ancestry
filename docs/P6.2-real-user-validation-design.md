# P6.2 — Real User Validation · 机制设计（Runnable Playbook）

日期：2026-10-04 ｜ 性质：机制设计 + 可执行化。**PASS 判定只能由真实用户执行后做出——本阶段禁止并未虚构任何用户数据。**
被验证的命题：**用户是否愿意持续把自己的视觉记忆交给系统，并在创作时回来调用它。**
被验证的不是：AI 输出漂亮不漂亮。

---

## 0. 核心验证链与观测锚点

```
用户输入(自己的参考图) → Vision Layer → Personal Memory → Profile Layer → Retrieval Layer → Assistant Layer
```

每一环都有真实产品表面可观测（仪表化核对见 §6）。主观察命题：**用户是否认为「这是我的视觉记忆」**——操作化为 Task 2 的 A/B 判定语与五指标。

## 1. 测试对象（5-10 人，三群体）

| 群体 | 人数 | 招募筛选（Screener 要点） |
|---|---|---|
| **A 影视创作者（核心）** | 3 | 导演/摄影/剪辑/分镜任一；有存参考图习惯（任一工具：Eagle/PureRef/相册文件夹均可）；未接触过本项目 |
| **B AIGC 创作者** | 2-3 | 有 20+ 张自己的生成图存档（MJ/SD/Firefly 任一）；能说出自己常用的提示词方向 |
| **C 普通设计用户** | 2 | 有存图习惯的设计爱好者/学生；**不了解 AI 工具细节**（产品边界测试需要） |

招募与激励、筛选表全文见 `work/p6.2-real-user/templates/recruitment-screener.md`。同一批人可顺带完成 P6.1 的 Landing 5-second test（先测文案再进产品，避免相互污染：**先 Landing 后产品**）。

## 2. 任务脚本（照读，零解释原则与 P5.8.2 相同）

### Group A（影视创作者）

- **建库指令**：「上传你过去喜欢的 20 张参考图。」来源不限：电影截图/摄影/绘画/自己项目参考。
- **Task 1（理解）**：上传完成后问——「这些图片变成你的视觉语言了吗？」
  观察能否用自己的话提到：空间 / 色彩 / 人物关系 / 构图（命中 ≥2 项记「理解」）。
- **Task 2（归属判定，核心）**：「找一个孤独的人在巨大空间里的参考。」
  结果展示后问：「这些结果对你来说更接近哪种？」
  - A：*找到类似图片*
  - B：*找到我以前喜欢这种感觉的东西* ← **B 才成立**（这是「我的视觉记忆」命题的直接检验）
- **Task 3（创作使用）**：「设计一个新的荒原镜头。」
  观察用户是否**自发**使用 retrieval 结果与 profile 数据（不提示；记录用了哪个、怎么用）。

### Group B（AIGC 创作者）

- 上传 20-50 张自己的生成图。
- 打开「我的视觉档案」，问：「你过去保存的图有什么共同视觉倾向？」
  **合格输出形态**（产品已保证）：统计句式——`低饱和 76% / 大空间 68% / 人物远距离 55%`；**不合格即红线**：任何「你的风格高级」式评价（产品有 QA 断言背书，理论上不出现，出现即 BLOCKER）。
- 关键问题：「这是你的生成方向吗？」（1-5 分 + 复述理由）

### Group C（普通设计用户，边界测试）

- 上传 10 张喜欢的图片。
- 事后问：「这个产品更像 Pinterest，还是更像你的个人视觉档案？」
  观察能否区分「收集/发现别人的图」vs「记住自己的选择模式」。C 组的价值是**找到产品不适用的人群边界**，不是挽回他们。

## 3. 五指标（量化，不只问满意度）

| # | 指标 | 测法 | 目标 |
|---|---|---|---|
| 1 | **Time to Value** | 场次录像计时：打开产品 → 用户第一次说出/表现出「有用」（主持人在上传完成、首次检索结果出现两个时点探针：「此刻它对你有用吗？」） | <5 分钟（≥70% 用户） |
| 2 | **建库意愿** | 上传 10+ 张后问：「你愿不愿意继续上传？」1-5 分；并观察是否实际「再传几张」 | ≥50% 用户 ≥4 分 |
| 3 | **检索价值** | 展示搜索结果后问：「这些结果是否比普通搜索（文件夹/相册关键词）更接近你的想法？」1-5 分 | 核心用户（A 组）≥2/3 给 ≥4 |
| 4 | **长期价值** | Day 7 中性回访（无任务指令，见模板话术）：用户是否在 48h 内主动打开并自行使用（上传/检索/看档案任一） | ≥1 人主动再次打开 |
| 5 | **信任** | 三个直接探针（逐条问，记录原话）：① AI 会不会评价我的审美？② 担心数据被利用吗？③ 这些结果是你自己的吗？ | ①③ 误解率 ≤1/3；② 任何「担心数据被利用」都视为 local-first 信息传达失败，记 CRITICAL 并当场澄清（「数据只在你电脑上」） |

## 4. 测试流程（Day 0 / Day 1 / Day 7）

```
Day 0  安装/打开 → 上传 20 张 → 生成 Archive
       记录：总耗时、每个卡点、逐字问题、Time to Value
Day 1  找参考任务 → 测 Retrieval（Group A 跑 Task 2/3；B/C 按各自脚本）
       记录：检索价值评分、A/B 判定语选择
Day 7  中性回访（无引导话术）→ 观察是否主动打开
       引导用户：上传更多 / 查看 Profile / 使用 Assistant（仅在其主动打开后）
       记录：是否主动、用了什么、长期价值评分
```

运营约束（重要）：
- **provider 配额**：真实上传走真实 vision（7-114s/张）。**每天最多排 2 名用户**（2×20=40 张，配额安全线内）；B 组 50 张上限者单日只排 1 人。
- **环境隔离**：每人一个全新浏览器 profile（无 localStorage 残留）；本机测试用 `MEMORY_STORE_DIR` 独立目录。
- **合规**：录屏需口头同意并记录；数据不出用户机器（local-first 是隐私卖点，也是本次测试的隐私优势，如实告知）。

## 6. 通过标准（预登记，执行后按此判定）

```
P6.2 PASS（全部满足）：
□ 产品理解：≥70% 用户理解「这是我的视觉记忆系统」（Task 1 命中 ≥2 视觉维度）
□ 建库行为：≥50% 用户愿意继续添加图片（指标 2 ≥4 分）
□ 创作价值：核心用户（A 组）≥2/3 认为检索结果有帮助（指标 3 ≥4 分）
□ 长期价值：≥1 人 Day 7 主动再次打开（指标 4）
□ 信任底线：无「AI 评价审美」类误解留存；「数据被利用」担忧当场澄清后消失
```

任一不满足 → 如实记录失败项 → 回到对应层面修复（文案/引导 = P5.8.2 授权面；机制层 = 记录为产品限制，不硬修）。

## 7. 结果 → 战略决策树（衔接 P6.1 Q3）

```
P6.2 PASS
  ├─ 强（4-5 项超标）：进入 P6.3 Cloud Decision（账号/云同步/数据库/多设备是否有必要）
  └─ 弱（压线）：保持作品集项目（A），扩大真人样本复测
P6.2 FAIL
  ├─ 失败在理解/文案层：最小文案修复 → 小样本复测（不换方向）
  ├─ 失败在价值层（「没用」）：回到 P6.1 定位复盘，方向降级为 A（作品集）
  └─ 失败在信任层：BLOCKER，产品叙事重来
```

对应 P6.1 的三个选项：**A 保持作品集项目 / B 个人创作者工具 / C SaaS 产品**——由 P6.2 实测数据决定，不由偏好决定。

## 8. 仪表可行性核对（逐任务 → 真实产品表面）

| 观测点 | 产品表面 | 已有证据 |
|---|---|---|
| Task 1 视觉语言理解 | 条目详情页视觉语言字段（情绪/色彩/构图/空间/人物关系） | P5.8.2 Task 3 三画像均能复述 ✅ |
| Task 2 检索+归属判定 | `#memory/search` 结构化 chips + reasons 卡片 | P5.8.3 九案例 reasons 100% 在场 ✅ |
| Task 3 创作使用 | retrieval + profile 数据（`#memory/profile`）+ Assistant creative_support | P5.7 三场景走通；P5.8.4 方向统计被 User A 用于分镜类比 ✅ |
| Group B 共同倾向 | `#memory/profile` 统计句式 + 禁词纪律 | QA 断言零禁词（P5.6 起）；observation/tendency/pattern 诚实分级 ✅ |
| Group C 边界 | 首页 04·MEMORY 卡 + 档案页 | P5.8.2 User C 证明边界人群可识别（价值感知最弱为预期）✅ |
