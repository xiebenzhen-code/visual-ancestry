# P6.3.1-CORRECTION — Film Source Reality

日期：2026-10-06 ｜ 阶段：STEP 3 + STEP 4 ｜ 数据源：`work/p6.3.1c/film-source-audit.json`

---

## 0. 核心结论

> **不存在「可持续的公共电影视觉来源」。可用的只有公版默片，以及用户自己导入的截图。**

这不是覆盖不足，是**版权结构的必然结果**。下面是四条路径的实测。

---

## 1. 最重要的一条实测发现：free licence ≠ film frame

我此前断言「Blade Runner(1982) 不可能有免费剧照」。这一轮实测发现情况更微妙，也更严格：

| 影片 | Commons 命中 | CC/PD 文件 | **其中真实画面** | 那些 free 文件实际是什么 |
|---|---|---|---|---|
| Blade Runner (1982) | 20 | 0 | **0** | — |
| 2001: A Space Odyssey (1968) | 20 | 0 | **0** | — |
| **Rear Window (1954)** | 20 | **20** | **0** | poster / publicity-still / unclear |
| In the Mood for Love (2000) | 4 | 4 | **0** | unclear |
| Tokyo Story (1953) | 20 | 20 | **1** | poster + 1 张待核实 |

**Rear Window 有 20 个自由许可文件，但没有一张是电影画面。** 实测其内容为：

```
File:Blade Runner - Ridleyville Map (fan made)        CC BY-SA 2.0   ← 同人地图
File:ExpoSYFY - Blade Runner (8522248276).jpg        CC BY 2.0     ← 剧本/道具的展览照片
File:Deckard's Sedan Blade Runner Petersen Museum    CC BY-SA 4.0   ← 博物馆里的道具车
File:"More Human Than Human" — Ridley Scott          CC BY-SA 4.0   ← 展陈照片
File:BR1982.png                                     Public domain   ← 电影 logo
```

**关键区别**：CC BY 覆盖的是**上传者拍的那张照片**，不是电影画面。拍摄博物馆里的一辆 1982 年道具车不侵犯电影版权——这张照片是 photographer 的作品。

> **所以「free licence」这个维度根本无法用来判断能不能用作视觉参考。唯一有效的维度是「它是不是一张电影画面」。**

## 2. Path A — Wikimedia Commons（公版剧照）

### 实测：21 部影片，7 部有真实画面

| 影片 | 年份 | 类型 | 真实 frame |
|---|---|---|---|
| Intolerance | 1916 | 黑白 | 1 |
| The Kid | 1921 | 黑白 | 3 |
| **The Toll of the Sea** | 1922 | **彩色(Technicolor)** | 3 |
| Metropolis | 1927 | 黑白 | **20** |
| The Lodger | 1927 | 黑白 | 2 |
| City Lights | 1931 | 黑白 | 2 |
| Modern Times | 1936 | 黑白 | 1 |

### 覆盖能力

| 维度 | 实测 |
|---|---|
| 黑白片 | **6/12 有画面** |
| **彩色片** | **1/9 有画面**（仅《The Toll of the Sea》） |
| 覆盖轴 | colour-design / architecture / urban / solitude / night |
| 缺失轴 | interior / crowd / sea / landscape / high-contrast |

### 为什么彩色片几乎为零

Commons 的默片剧照主要来自**档案照片与出版物扫描**，而彩色片（1930s–50s）仍在版权期。唯一命中的《The Toll of the Sea》(1922) 是因为它是**首部 Technicolor 影片，版权已过期**。

**这是一条硬边界，不是检索能力问题。**

## 3. Path B — Internet Archive

```
mediatype:movies AND year:[1920 TO 1929]  →  411 items
```

IA 有**完整的公版默片文件**（不是剧照，是影片本身）。这意味着：

| 能力 | 状态 |
|---|---|
| 公版默片可获取 | ✅ 411 部（1920s） |
| 可否抽帧 | ❌ **本环境无 ffmpeg**，无法从影片抽帧 |
| 可否直接用作视觉参考 | ❌ IA 提供的是视频文件，不是剧照 |

**这是一条能力缺口，不是覆盖缺口。** 若装上 ffmpeg，IA 是比 Commons 更好的公版来源（可控、可抽帧、可精确定位）。

---

## 4. Path C — TMDB / 版权图片提供方

```
TMDB image CDN 可无 key 取图 (200)
但每张 still 的 URL 必须由需要 key 的 API 调用生成
```

**没有 key 就没有 still 搜索。** 而有 key 也不改变版权状态——TMDB 提供的是**授权范围内的宣传物料**，产品把它当作视觉参考需自行承担授权判断。

**结论：不构成合法的公共电影视觉来源。**

---

## 5. Path D — 用户截图导入（唯一可扩展到现代电影的路径）

已在 P6.3.1 STEP 6 验证：

```
30/30 用户电影截图 → Image → Intent → Memory → Retrieval
22 条引用 · 0 泄漏 · 100% 带 reason · 0 次导演式话术
```

**这是唯一能覆盖现代电影的方式**，而且它恰好是产品应该做的那件事：

> 用户想的是「我记得《银翼杀手》里那个雨夜的镜头」，不是「请帮我从电影数据库里找图」。

## 6. 四个问题的直接回答

### Q1 · Public-domain film source 能覆盖到什么程度？

**仅公版默片与极少数早期彩色片。** 实测 21 部中 7 部有真实画面，其中彩色仅 1 部。可用视觉语言轴为 urban / architecture / solitude / night / colour-design —— **缺 interior / crowd / sea / landscape**。

**它无法支撑「电影视觉」这个产品定位**，只能作为补充。

### Q2 · Contemporary famous films 能否由公共接口合法提供 frame/still？

**NO。** 五部当代/知名影片实测：`actualMovieFrames = 0, 0, 0, 0, 1`。

Rear Window 有 20 个 CC 文件但**零张电影画面**——因为 CC 覆盖的是拍摄者的照片，不是电影。这比「没有文件」更能说明问题：**存在文件不等于存在可用素材。**

### Q3 · User Screenshot Import 是否必须成为现代电影的主要入口？

**YES，必须。** 理由：

1. 公共接口在版权上**不可能**提供现代电影画面
2. Path D 已被实测验证可行
3. 它符合产品定位——Visual Archive 是**个人**视觉记忆系统，不是电影数据库

### Q4 · 是否存在值得正式接入的电影视觉数据库/API？

**当前没有。** 逐一评估：

| 候选 | 判断 |
|---|---|
| TMDB | 需 key，且提供的是授权宣传物料，非自由可用 |
| IMDb | 无公开图片 API |
| 商业图库（Getty/Alamy） | 需采购，且多为剧照而非原始画面 |
| Internet Archive | ✅ **值得接入，但需先装 ffmpeg**；411 部公版默片是真实资产 |
| Wikimedia Commons | ✅ 已接入，但需**精确标题检索**而非全文搜索 |

**建议**：正式接入 **Internet Archive**（公版默片抽帧）+ Commons 精确检索，作为**补充**；电影的主入口仍是用户导入。

## 7. 产品策略结论

```
电影视觉来源（按可靠性排序）

1. 用户截图导入          ← 唯一覆盖现代电影的方式，已验证
2. Internet Archive 抽帧  ← 公版默片主力，需 ffmpeg
3. Commons 精确检索       ← 公版剧照补充，需 intitle: 而非全文搜索
4. TMDB / 商业图库        ← 不建议，需采购且非自由
```

**不要把电影做成一个内置数据库。** 用户收藏的剧照本身就是入口，而且它才符合「个人视觉记忆」这个定位。
