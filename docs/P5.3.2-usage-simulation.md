# P5.3.2 STEP 5 — Product Usage Simulation（使用模拟）

Date: 2026-10-02 · 模拟三阶段用户旅程 · 基于真实池实测数据（P5.2.4 / P5.3.1 / P5.3.2 压测池）

## 阶段一：第一次使用（输入 10 张喜欢的镜头）

**旅程**：`#memory` → 「＋ 保存一段新素材」→ 拖入 10 张 → 逐张实时转译 → 失败卡片可见可重试。

**是否理解保存价值？** 判定：**理解，因为保存即获得语言**。证据链：
1. 上传零标签（P5.2.4 实测）：用户只给一个编辑性名称，其余全部由转译完成——保存的成本极低
2. 即时回报：每张上传完成立刻得到 25 字段视觉语言（「深空间 / 环境主导 / 孤立 / 低饱和」），**用户第一次看到自己的审美被说出来**（P5.2.4 STEP 3：80% 转译产生创作语言）
3. 失败不惩罚：失败卡片保留 + 中文原因 + 一键重新分析（P5.1.8 契约；P5.3.2 压测闭环数据见报告 §1）
4. 风险：首传失败率是最可能的流失点（压测实测 ~75-80% 首传成功，重试后 ~95%+）——闭环已建立，但「失败的原因」对非技术用户仍偏技术（VISION_INVALID_RESPONSE 类文案已中文化但不够「人话」）

## 阶段二：积累阶段（50 张后是否开始主动检索）

**旅程**：`#memory` → 「按感觉寻找 →」→ 结构化选择（氛围/空间/色彩/饱和度/人物）→ 结果带理由。

**是否开始主动检索？** 判定：**会，且检索是积累的直接受益者**。证据链：
1. 检索价值随池增长而增长：P5.2.4 实测 5 个创作语言 Case 中 3 个精确命中（孤独大空间/巨大环境小人物/环境压过人物）；池越大，命中越准
2. 理由展示（evidence）让检索**可信**：用户看到的不是黑箱推荐，而是「✓ 环境压过人物 / 纵深很深 / 留白很大」——这与「为什么当时收藏它」的记忆对得上
3. 诚实限制同样可见：池里没有的内容查不到（P5.2.4 Case2 旧工业城市夜晚弱召回），系统不假装命中——这反而建立信任
4. 风险：结构化选择（无自然语言）是第一版刻意的范围决策——高频用户会想要「直接说一句话」的输入；这是 V2 Alpha 之后的候选能力，不是缺陷

## 阶段三：创作阶段（生成「孤独荒原镜头」的参考流程）

**流程实测**（P5.3.2 STEP 3 跨媒介检索，隔离压测池）：

```
感觉：「孤独的人站在巨大环境中」（创作语言）
  ↓
搜索：VisualQuery = 寂静 + 深空间 + 环境主导 + 大留白 + 孤立（schema token，无 NLP）
  ↓
找到参考：top5 跨媒介返回（电影剧照 + 山水画 + 版画混排，按视觉语言打分）
  ↓
查看匹配理由：每条展示「环境压过人物 / 人和环境的距离很远 / 氛围·寂静」
  ↓
调用参考：点击进入 #memory/:id 详情，完整视觉语言可直接转述为创作提示
```

**关键实测发现**（详见表 `cross-media-results.json` 与报告 §2）：电影与绘画在视觉语言层**确实共享同一检索空间**——「孤独的人站在巨大环境中」同时召回电影远景与中国山水，因为两者被同一种语言描述（深空间/环境主导/孤立）。这正是「跨媒介找感觉」的产品价值：用户存的是素材，找到的是语言。

**诚实边界**：部分创作语义（梦境/超现实/工业城市）在 schema token 空间中不可完整表达（P5.3.2 Case 2/4 映射子集，部分召回）；画像层 emotion 不可用（冻结 Vision 层产出稀疏）。
