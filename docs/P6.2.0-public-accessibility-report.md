## 4. 失败记录（如实）

1. **agent-browser 守护进程在本沙箱卡死**（Chrome 启动阻塞，1h39m 无响应）→ 改用仓库既有 CDP Edge 方案成功。
2. **本机沙箱代理对部署域名 502** → 无法从本机直测公网；外部网络位（WebFetch）替代验证可达性。
3. **公网上传 501** → 非缺陷，是「静态托管 + 凭据仅在服务端」架构锁的必然行为；按 P6.1「NOT YET 云化」决策，当前不做服务端公网部署。

**总判定：PASS WITH LIMITATIONS。** 公网部署可达、产物在真实浏览器全链路（导入→记忆→检索→画像→Assistant）验证通过；「跨地区真机矩阵」与「公网上传链路」两项移交 P6.2.1（真人测试时用户自带网络与设备自然覆盖前者；后者依赖是否提供带凭据的服务端部署，属 P6.3 Cloud Decision 范畴）。
