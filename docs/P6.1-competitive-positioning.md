# P6.1 — STEP 4 竞品定位分析 + STEP 5 Landing Page 价值测试设计

日期：2026-10-04 ｜ 定位分析基于公开产品常识与本项目验证事实，不做功能对标清单。

---

## STEP 4 · 竞品定位（按「解决什么问题」分层，非功能比较）

### Reference Management（Pinterest / PureRef / Eagle / Are.na）

- **解决**：收藏。存得快、看得爽、板子拼得美。
- **不解决**：**为什么喜欢**。Pinterest 是别人的推荐流（且把你拖回无限刷）；PureRef/Eagle 的画板记得「放在哪」，不记得「那纵深、那侧光为什么击中你」；图片之间没有共享视觉语言，无法跨媒介检索。
- **与 Visual Archive 的关系**：上游。收藏工具产出的「图堆」，正是视觉记忆系统的输入。兼容而非替代——可做导入源。

### AI Image Tools（Midjourney / Firefly / SD 生态）

- **解决**：生成。从提示词到图。
- **不解决**：个人视觉记忆。它们记住的是 prompt，不是「你这三年一直在选低饱和、深空间、环境压人的画面」；生成越多，越需要一个新的锚——它们没有这个锚。
- **关键区分**：生成是「从无到有」，视觉记忆是「从有你到懂你」。两者互补：Archive 的档案/参考包恰好可以成为生成工具的输入（P5.7 已验证「个人记忆→创作提示」链路，且明示不是 AI 创作）。

### 定位图

```
收藏工具（Pinterest/PureRef/Eagle）
        ↓  解决「图堆没有记忆」
视觉记忆系统（Visual Archive —— 本项目：Local-first、可解释、个人档案）
        ↓  解决「记忆不会辅助创作」
创作者辅助层（参考包 / 视觉 Bible 数据底稿 —— 已验证的最薄一层）
```

**一句话卡位**：在收藏与生成之间的空档——**没有人保存「你的眼睛」**。Visual Archive 保存的是选择模式，不是图片堆。

## STEP 5 · Landing Page 价值测试设计（不实际投放）

### 三个 Hero 文案

| 版本 | 文案 | 预期信号 |
|---|---|---|
| **A** | Build your personal visual memory. | 价值直给；风险：偏抽象，「memory」可能被理解为云相册 |
| **B** | Find references by feeling, not keywords. | 功能直给；风险：被理解为「AI 相册搜索」 |
| **C** | AI that remembers why you saved an image. | 差异化最强；风险：**被误读为 AI 生成工具**（最高误解风险，需重点测） |

### 测试设计（5-second test + 意向探针，每版本 ≥12 人）

1. **5 秒曝光** → 自由复述「这个产品是做什么的」（测 Q1 理解准确率）。
2. **意图题** → 1-5 分「愿意试」（测 Q2）。
3. **误解探针** → 「它会帮你生成图片吗？」（测 Q3 误读率——版本 C 的关键指标）。
4. **首屏追问** → 「你会在什么时候用它？」（测场景自发联想，对应 Persona A/B/C 命中度）。

### 判定标准（预登记）

| 指标 | 及格 | 优秀 |
|---|---|---|
| Q1 理解准确（复述含「收藏/记忆/视觉」且不含「生成」） | ≥60% | ≥80% |
| Q2 愿试（≥4 分） | ≥40% | ≥60% |
| Q3 误读为生成工具 | ≤20% | ≤10% |
| 场景联想命中创作场景 | ≥50% | ≥70% |

### 预判与备选

- 预判：B 理解准确率最高但差异化弱；C 差异化最强但误读率最高。若 C 误读 >20%，备选改写：**"It remembers why you saved it."**（去掉 AI 主语，保留差异化、降低误解）。
- 落地路径：任一版本达标 → 作为 `portfolio/visual-archive-final/` Hero 副标题与简历一句话的 A/B 备选；全部未达标 → 回到 STEP 0 一句话定义重写（数据驱动，不拍脑袋）。
