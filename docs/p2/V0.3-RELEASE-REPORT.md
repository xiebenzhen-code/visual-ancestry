## 七、本轮发现并修掉的问题

1. **限速自伤**：Commons 图床 429 的 `Retry-After` 可能是几千秒，原实现照单全睡，整轮采集被拖死 → 等待上限 2.5 秒，超时记失败。
2. **验收被自己的限速挡住**：`/api/discovery/neighbors` 6 次/分，48 张复核直接 429 → 默认提到 12 次/分，验收脚本用显式环境变量放宽并在报告注明。
3. **片名字卡混入**：`Pisacane bis` 画面是黑底白字片名 → 过滤规则加描述字段与 `titolo/titel`，并人工移除该条；OCR 识别仍未实现。
4. **文案撒谎**：动画档空栏写"库里还没有动画素材"，而库里已有 20 张 → 改为"本地档案分支没有"。
5. **录屏时长失真**：screencast 只在画面变化时给帧，静态停留被压成 1 帧 → 改为固定 5fps 抓帧，时间戳即真实停留。
6. **跨媒介排序**：加入结构相似度（明度分层/不对称/画幅/边缘密度）并给黑白帧降权 0.7；整体比例未质变，报告里不把它包装成提升。
