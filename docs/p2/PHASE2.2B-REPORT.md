# Frame Atlas v0.3 Phase 2.2B — 跨媒介视觉探索验收

日期：2026-10-21 ｜ 分支：`develop/v0.3-visual-explore` ｜ 基线：`3d14d4a`

结论先说：**四条路径都能稳定返回真实候选，但跨媒介的视觉关联整体偏弱。** 有效 3 / 弱 24 / 错误 21 / 无候选 0（共 48 张，有效 6.3%）。这不是"没取到数据"，而是 512 维 MobileCLIP-S0 的余弦衡量的是同一媒介内的内容相似，抓不住跨媒介真正可解释的对应（构图骨架、光型、影调）。

---

## 一、方法

- 每个路径 3 个真实起点，共 4 路径 = 12 个起点，每个起点取前 4 张该媒介候选，共 48 张。
- 起点：**雨天的巴黎街道**、**神奈川冲浪里**、**美国哥特式**（湿冷街景 / 强动态海浪 / 正面肖像，三种不同视觉条件）。
- 电影起点：Tears of Steel 95s、140s、Collapse of the Funnel；动画起点：BBB 30s、60s、Billiondollarlimited1。
- 取数：`qa/p22b-crossmedia.mjs` 调线上同源接口 `/api/discovery/neighbors`，把"起点 + 候选"排成对照图（`contact_sheet.py`）。
- 判定：人工逐张看对照图，标准写在 `verdicts.json`：
  - **有效** = 能说出具体的构图/色彩/光影/空间对应
  - **弱** = 同媒介但只有笼统气质相近，说不出结构对应
  - **错误** = 内容与视觉结构都无关
- 没有用任何自动评分替代人工判定，也没有为了好看调整阈值。

## 三、本轮做的小范围修复（都有证据）

1. **结构相似度重排**（`structureScore`）：同媒介候选按 `0.5·cos + 0.5·结构相似` 排序，结构 = 明度三段分布 + 不对称度 + 画幅 + 边缘密度。效果可核对：动画→绘画里那条"有效"从第 2 位升到第 1 位；绘画→电影里 Metropolis（黑白、结构相近）上浮。**整体比例没有质变，不把这算作品质提升。**
2. **黑白降权 0.7**：黑白帧在界面电影/动画档里本来就被排除，排序时先降权，避免占掉可见位次。
3. **片名字卡过滤补强**：把描述也纳入排除（`titolo`/`titel`/`título` 等）。仍然漏了一张 —— `Pisacane bis`（Public domain）画面实为黑底白字片名，标题/分类/描述都不暴露这一点，需要 OCR 才能自动识别。已人工移除这一条并登记为缺口。

## 四、对产品的含义（如实写）

- 跨媒介**可以探索**，但当前只能提供"值得一看的参考"，**不能宣称风格一致**。界面上这一行本来就叫"同媒介视觉近邻（仅向量，未做风格判定）"，与本轮结论一致。
- 想真正提高跨媒介质量，需要换更强的视觉编码器或引入构图/影调的结构化匹配，属于下一版本的工作，不在本轮范围内扩架构。
- 分布上：动画素材只有 20 张，可选面最窄，绘画→动画是四条路径里最差的（0 有效）。
