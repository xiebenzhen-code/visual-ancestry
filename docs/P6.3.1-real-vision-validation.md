## 5. 若 60 张仍达不到 9/10

**先诊断 VisualIntent，不允许靠扩大资产数量解决。**

诊断顺序：

1. **intent 稀疏度** —— 60 张里 `atmosphere` / `negativeSpace` 的产出率。若 <40%，是 vision 层的字段产出问题（P6.2.1 曾记录 `emotion` 产出率仅 2–13%）
2. **跨媒介字段缺口** —— 统计电影与绘画各自能表达哪些字段，若一侧恒为 0（如 P6.3 的 `colorTemperature:cool`），是 schema 表达力问题
3. **评分权重** —— 冻结 `scoring.js` 的 WEIGHTS 是否让某类字段被低估
4. **池规模** —— 30+30 是否样本太少导致 top-10 被单一媒介占满

**不允许的解法**：把 60 张扩到 600 张。上一轮已经证明扩规模不解决问题——那轮 496 张全部 `rule-fallback`，跨媒介反而只有 7/11。
