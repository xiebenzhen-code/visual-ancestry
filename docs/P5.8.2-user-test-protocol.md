## 0. 测试目的与假设

**核心问题：一个不了解项目背景的真实用户，能否独立建立自己的视觉记忆库，并理解为什么这个系统有价值？**

假设（来自 STEP 0，待证伪）：
- H1（B 类）：首页动线不含 MEMORY，用户不易发现个人档案入口。
- H2（C 类）：上传完成后用户不知道「接下来能用它做什么」。
- H3（C 类）：用户不会自发形成回访动机。

## 1. 用户画像（Protocol 定义）

| 用户 | 背景 | 素材准备 | 预期风险 |
|---|---|---|---|
| **User A** | 影视 / AIGC 创作者，日常有分镜、风格参考习惯 | 参考图 + 分镜风格素材 8-10 张（电影剧照、概念图） | 低。最可能走完全部六任务 |
| **User B** | 普通设计兴趣用户，有存图习惯但不了解视觉语言概念 | 电影截图 + 艺术图片 6-8 张 | 中。可能在「视觉语言」抽象层困惑 |
| **User C** | 不了解 AI 工具的普通用户，只会存照片 | 随手拍 / 截图 5 张 | 高。最可能停在 Task 1-2 |

> **诚实声明：本次为结构化模拟（Structured Simulation），非真人测试。** 模拟者（AI）按画像逐任务走查真实 UI 代码路径与真实数据，输出与真人测试同 schema 的记录；模拟结果只能证明「路径是否走得通、文案是否可理解」，不能替代真人反应时间与情绪数据。真实用户测试清单（招募标准 / 环境记录表）留白于 §6，供后续真实测试直接使用。

## 2. 六项任务（Test Script，对用户零解释）

执行纪律：主持人在 Task 1 全程只说「请打开这个网站，想做什么就做什么」，从 Task 2 起也只读任务原文，不解释产品。

- **Task 1 首次接触**：打开首页。记录：用户说出「这是什么」的原话、视线停留区、第一个点击。
- **Task 2 建库**：自己选 5-10 张图上传（来源不限）。记录：选图逻辑、是否中断、是否问「上传的图去哪了」。
- **Task 3 查看 AI 分析**：查看任一已存条目的分析。记录：用户复述「AI 看到了什么」；是否提到情绪/色彩/构图/空间/人物关系中的任一类。
- **Task 4 Search**：任务原文：**「找一些适合孤独旅程场景的参考」**。记录：输入了什么词（自然语言还是标签）；是否读懂每条结果下的「为什么找到」。
- **Task 5 Profile**：打开「我的视觉档案」。记录：用户把它理解为「我的收藏统计」还是「AI 判断我的审美」——**必须出现前者，后者为红线**（禁词纪律：审美等级/人格/比别人/评分/你的风格是）。
- **Task 6 Assistant**：任务原文：**「帮我找适合下一段创作的视觉参考」**。记录：用户是否认为结果「来自自己的记忆」；是否出现「AI 替我创作」的误解。

## 3. 测量（Measurement Schema）

每个用户一份 JSON，严格按 spec：

```json
{
  "userType": "A | B | C",
  "firstUnderstandingTime": "<Task1 说出产品是什么所用时间/轮次，或 never>",
  "uploadCompleted": true,
  "searchUsed": true,
  "profileViewed": true,
  "assistantUsed": true,
  "confusionPoints": [{"task": 1, "desc": "...", "category": "A|B|C|D"}],
  "valueMoment": "<用户第一次表现出『这有用』的具体时刻，或 none>"
}
```

失败分类（spec 固定）：
- **A** 用户不知道产品是什么
- **B** 知道但入口不明显
- **C** 理解但价值不足
- **D** 技术阻塞

## 4. 执行方式（本环境）

- 走查对象：真实 UI 代码路径（`home.js` / `memory.js` / `memorySearch.js` / `memoryProfile.js` / `memoryAssistant.js`）+ 真实数据池（34 条生产 memory 语义，来自 P5.6/P5.7 验证过的池子语义）。
- 每个用户的每个任务输出 `work/p5.8.2-user-validation/simulation-{A,B,C}.json`（含逐步观察记录）+ 汇总 `measurement.json`。
- 判定红线：Task 5 出现「AI 审美判断」理解 → 立即记 C 类严重项；Task 4/6 结果不被理解为「来自自己的记忆」→ 记 C 类。

## 5. 决策规则

| 模拟结果 | 动作 |
|---|---|
| 全部六任务通过，混淆点 ≤1 且为轻度 | 不修复，直接进 STEP 6 报告 |
| C1-C4 任一被模拟真实触发（B/C 类） | STEP 4 最小文案修复（授权面内）→ STEP 5 重复模拟验证 |
| 出现 D 类技术阻塞 | 停止，报告 BLOCKED |
| Task 5 红线触发 | 检查是否文案层可修；Profile 算法本身冻结，若需算法改动则记录为限制而非修复 |
