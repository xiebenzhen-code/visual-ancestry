### ⚠️ 两个必须记录的边界事实

1. **模块命名冲突**：`src/utils/profile.js` 已存在（170 行，Phase 2 时代的**浏览行为日志**：localStorage `va-profile-v1`，track viewedArtwork/savedArtwork 等事件，服务于 `#eye` YOUR EYE 页）。→ P5.3 Personal Layer 新模块**不得叫 `profile.js`**，建议 `src/services/memory/visualProfile.js`（聚合器）。
2. **`#eye` 与 `#memory/profile` 是不同产品**：`#eye` = "你可能喜欢什么"（**浏览行为**数据源：全球艺术库交互事件）；`#memory/profile` = "你的收藏是什么倾向"（**个人资产**数据源：visualIntent 聚合）。**不同数据源不合并**——P5.3 只聚合个人池 visualIntent，不读 `va-profile-v1`。两页面语义不同、互不引用，避免"数据分析软件"化。

## 3. Profile Schema Proposal（只设计，不实现）

```ts
VisualProfile {
  id: string                  // "default"（单用户本地档案）
  sampleSize: number          // 19
  sampleSource: "personal-pool"   // 永远不含浏览行为（与 #eye 数据隔离）
  generatedAt: ISOString

  spatialProfile: {           // 空间倾向（0-1 占比，真实可算）
    deepSpace: 0.84,              // spatialDepth=deep
    environmentDominant: 0.63,    // environmentDominance=high
    negativeSpaceHigh: 0.47,      // negativeSpace=high
  }
  compositionProfile: {       // 构图（用真实可用字段，不用空字段）
    centeredSubject: 0.89,        // subjectPosition=center
    farCamera: 0.53,              // cameraDistance=far
    staticFrame: 0.89,            // motion=still
  }
  colorProfile: {
    lowSaturation: 0.84,
    neutralTone: 0.53, coolTone: 0.26, warmTone: 0.21,
    highContrast: 0.79,
  }
  narrativeProfile: {         // 叙事关系——不是"喜欢悲伤"，是关系结构
    isolation: 0.58,              // humanRelation=isolated
    socialDistanceHigh: 0.53,
    quietArousal: 0.63,           // arousal=low
    melancholyMedium: 0.53,
  }
  atmosphereTokens: { 空旷: 8, 寂静: 4, 夜晚: 2, 热闹: 2, 雾: 2 }  // 稀疏标注
  unavailable: {              // 诚实清单
    emotion: "3/19 非空，样本不足",
    composition: "冻结 Vision 层产出为空", geometry: "同左",
    cameraHeight: "95% 单值无区分度", cameraRelation: "同左", lightDirection: "同左",
  }
  confidence: "observe"       // 见 §4
  basis: "based on 19 visual memories"
}
```

设计原则：**每个数值都是池内真实占比的可读换算**（零新模型、零权重设计、零 embedding）；四组 profile 与冻结 `scoreIntent` 的 WEIGHTS 无关（聚合是计数，不是评分）。

## 4. Confidence Rules（防止伪造审美）

| 样本量 | confidence | 展示语言 |
|--------|-----------|----------|
| < 20 张 | `observe` | 「当前样本显示…」观察趋势 |
| 20–50 张 | `tendency` | 「你的收藏偏向…」稳定倾向 |
| > 50 张 | `pattern` | 「你的视觉模式…」个人视觉模式 |

**硬规则**：
1. 文案永远以样本量开头限定（`basis` 字段强制展示"based on N visual memories"）——**19 张时永远不说「你的审美是」**
2. 稀疏字段单独降级：atmosphere 附注「32% 收藏无氛围词」；unavailable 字段**不展示倾向、只展示诚实说明**
3. 无倾向字段如实说「未显现明显倾向」（colorTemperature/negativeSpace 实测如此）
4. 阈值边界处的文案切换由 `sampleSize` 决定，与内容质量无关

## 5. Product Boundary

- **形态**：Visual Identity Page（`#memory/profile`），**不是 dashboard**——没有图表控件、没有百分比矩阵墙
- **语言模板**（规则生成，非 LLM）：
  - 空间：「你经常选择让人物置于环境之中。」（environmentDominant ≥ 0.6 时）
  - 构图：「你的收藏偏向远距离观察与稳定的静止画面。」
  - 色彩：「低饱和与高对比出现频率较高。」
  - 叙事：「孤独、疏离的人际关系在你的收藏中反复出现。」
- **入口**：`#memory` 首页第三 CTA（「我的视觉档案 →」），与上传/检索并列——V1 UI Flow 冻结面的**新增**（P5.2.2 同类：新增路由/页面属产品层扩展，不改冻结组件，须在 P5.3.1 按 Freeze 规则三问说明）
- **与 `#eye` 的关系**：并存不合并（§1 边界事实 2）
- **禁止**：不做雷达图/对比分析/建议引擎/审美评分——画像只描述「已经收藏了什么」，永远不评价「应该喜欢什么」

## 6. Implementation Recommendation（P5.3.1 范围建议）

1. `src/services/memory/visualProfile.js`（命名避开已占用的 `utils/profile.js`）：
   - `aggregateVisualProfile()`：读 `listMemories()` → `isRetrievable` 过滤 → 纯计数聚合 → `VisualProfile`（只读冻结 schema 字段，零 scoring import）
2. `src/pages/memoryProfile.js` + 路由 `#memory/profile` + `#memory` 第三 CTA + 中文模板文案渲染
3. Confidence 按 §4 规则；unavailable 字段渲染诚实说明块
4. QA：`qa/memory/profile-test.mjs`（P5.2.4 池聚合断言：sampleSize=19 / deepSpace≈0.84 / unavailable 清单 / <20 文案级别）
5. **不做**：emotion 修复（冻结层）、composition/geometry 修复（冻结层）、`#eye` 数据合并、embedding

## 决策点回答

**A — 数据足够，进入 P5.3.1 Profile Aggregator MVP。**

理由：13 个结构/空间/色彩/叙事字段在 19 张真实收藏上已形成稳定趋势（深空间 84% / 低饱和 84% / 高对比 79% / 孤立 58% / 环境主导 63%），足以支撑「观察趋势」级画像；不可聚合字段（emotion/composition/geometry/3 个镜头字段）全部归属冻结 Vision 层产出问题，**Personal Layer 无法也不应调整**（决策 C 不成立——C 的前提「只调整 Personal Layer 可解决」对这些字段不适用）；扩大收藏池（决策 B）有价值但**不阻塞** P5.3.1——confidence 规则天然随样本增长升级文案，20 张门槛由 P5.2.4 池（19）+ 少量新增即可跨过。
