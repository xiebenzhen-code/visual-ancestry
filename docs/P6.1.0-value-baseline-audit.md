## 1. 当前产品一句话定义

> **Visual Archive is a personal visual memory system that helps film & AIGC creators and design students by turning the images they save into a searchable visual language, a growing profile of their own eye, and grounded creative references.**

禁词自查：未使用 AI Agent / 智能推荐 / 自动创作 ✅
（中文口径：**帮创作者保存和理解自己的视觉记忆的系统**——不是 AI 帮你找图，是帮你记住你为什么喜欢。）

## 2. 已验证事实（全部有出处）

| 能力 | 证据 |
|---|---|
| 图片理解 | 真实 vision 转译 112+ 次（P5.8.3）；schema 全字段（arousal/atmosphere/cameraDistance/humanRelation…）；49 件校准 cache unknownEnums=0 |
| 视觉语言转换 | 跨媒介同一语言：电影剧照与绘画并列命中同一查询（P5.9.0 Scene 3 实测：42 条混合池、8 hits/2ms） |
| 个人收藏 | Local-first：原图不持久化、浏览器/Node 双环境；Archive Contract V1 迁移 119/119 成功（P5.8.4） |
| 检索 | 按感觉检索 + reasons 100% 在场（P5.8.3 九案例）；零结果诚实返回（P5.5）；avg 0.45ms（P5.4） |
| Profile | 四组倾向统计；confidence 阶梯确定性（observation→tendency→pattern，跨用户一致，P5.8.4）；禁词纪律（无审美等级/人格/评分） |
| Assistant | 薄层三能力；grounding 泄漏 0（引用 ⊆ 个人池）；随个人历史正确演化（26→62 两时点对比，P5.8.4） |
| Creator Workflow | 三场景 + 跨媒介参考成立（P5.7）；「孤独旅人荒原」场景出电影+绘画参考包（P5.7 Case A / P5.9.0 Scene 3） |

## 4. 用户路径（现状）

```
首页(04·MEMORY卡) → 空状态引导 → 上传(批量/可重试) → 档案(四CTA)
  ├─ 按感觉找回(结构化 chips)
  ├─ 我的视觉档案(四组倾向)
  └─ Visual Assistant(三能力)
```

## 5. 当前限制（价值叙事的边界，同屏诚实）

Local-first 单用户、无云同步、5MB≈127 条（含缩略图）、单一 vision provider、真人测试未执行、100+ 规模待补。

## 6. 结论

产品能力已充分验证；**缺口全部集中在「真实用户是否需要、是否留存、是否愿付」**——这正是 P6.1 的对象。进入 STEP 1。
