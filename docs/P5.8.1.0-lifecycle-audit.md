## 2. 存储介质与数据字节事实（关键约束）

- **浏览器**：整库 JSON 存于 `localStorage["visual-memory:v1"]`。每条含 `metadata` + `visualIntent` + `userData`（其中 `thumbnail` = ≤420px JPEG dataURL，由 `src/pages/memory.js:makeThumbnail` 生成，0.72 质量）。`image.path` 仅是**文件名**，原始图片字节**永不持久化**。
- **Node/QA**：`image.path` 指向磁盘原文件（work/ 材料目录）；Node 上传路径**不生成 thumbnail**（仅浏览器路径生成）。`examples.json`（source=example）独立于 memories.json，永不进入检索。
- **容量**：每条 thumbnail dataURL ≈ 20–60KB base64；40 条池 ≈ 1–2.4MB，逼近 localStorage 5MB 配额风险（100 张压测目标下不可忽视）。
- **结论**：现有 browser persistence **不能满足** Export（无序列化出口）/ Clear（无整体清空，且 `browserCache` 模块单例须重置）/ Import（无入口，且须绕过缓存+校验）/ Restore（无一致性核验）。

## 4. 关键设计事实

1. **Export 的「图」问题**：浏览器数据只有 thumbnail（dataURL），原始图不在 localStorage。导出文件若要「可看」，只能带 thumbnail（诚实标注）；原图迁移属数据源（Node 磁盘材料/用户本地源图），不在本阶段补齐。
2. **Import 必须校验**：`createVisualMemory` 已强制 id/source/status/visualIntent 契约 → 导入走同一构造函数可获 schema 校验（含 failed 占位）。损坏 JSON / 非法条目必须拒绝且不回滚已有库（导入前备份）。
3. **Clear 的语义**：清空 ≠ 只删 memories 数组——须连 `browserCache` 模块单例一起重置（否则本会话残留）；Node 侧须落盘空库。
4. **Restore 一致性**：恢复后用「检索+画像」做一致性抽检（零改动冻结模块，只调用）——是验证「继续使用」的客观手段。
5. **命名**：新增模块遵循现有风格 `src/services/memory/*.js`；QA 脚本 `qa/memory/*-test.mjs`；文档 `docs/P5.8.1.*-*.md`。

## 5. 判定

**GO（带两条授权）** —— 生命周期缺口确凿且均为组合层可补：

- **授权 A**：新增 `archivePortability.js`（冻结外）承载 export / clear / import / restore 组合能力，调用冻结 `listMemories/addMemory` + `createVisualMemory` 校验，零重实现检索/画像/评分。
- **授权 B（最小修改）**：`memoryRepository.js` 仅当审计证明必需时加最小能力。审计结论：**必需**——浏览器 clear 需重置 `browserCache` 单例、import 需整体替换 store（二者都无法在冻结外以组合调用达成）→ 最小修改方案：为 repository 增加 `clearMemories()` / `replaceAllMemories()` 两个原语（保持既有 API 未动、双环境一致、幂等），不触碰任何检索/评分/画像逻辑。
- **冻结三问（P5.8.1 记录）**：`router.js` + `memory.js` 的加法修改（#memory/settings 路由 + 入口 CTA）——① 为什么：生命周期 UI 需要入口；② 是否破坏边界：否（加法路由/CTA，不改既有行为与数据规则）；③ 是否新版本：P5.8.1 为用户显式授权的 Lifecycle 阶段。

**确认不做**：不需要 IndexedDB（当前 localStorage + 单 JSON 文件已满足本次生命周期最小闭环；配额问题在 100+ 张时以「导出→归档→清库」产品路径缓解，不引入存储引擎迁移）；不需要 ZIP（JSON 单文件即最小可迁移单元，文件类型对用户可读诚实）；导出格式 = versioned JSON（`{format:"visual-archive", version:1, exportedAt, store:{version,memories}}`）。
