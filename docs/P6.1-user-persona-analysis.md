## STEP 1 · 三个 Persona（产品假设，非用户研究）

### Persona A · Film Creator（影视导演 / 分镜师）

**痛点假设**：参考图片越来越多，但几年后找不到「为什么喜欢」——文件夹只记得文件名，不记得那张图的构图逻辑。

**Visual Archive 是否减少——**

| 目标 | 现有证据 | 判定 |
|---|---|---|
| 搜索时间 | 「孤独旅人荒原」→ 8 hits / 2ms，跨媒介并列命中且带 reasons（P5.9.0 Scene 3 实测） | ✅ 已验证（速度与相关性层面） |
| 参考整理成本 | 收集路径零阻塞：三画像六任务全过、上传批量+失败重试闭包（P5.8.2/P5.8.3） | ✅ 流程已验证 |
| 灵感丢失 | 画像统计把「无意识倾向」显性化——User B 实测反馈「它把我没意识到的倾向说出来了」（P5.8.2 Task 6）；visual Bible 数据底稿（P5.7 Case C） | ✅ 机制已验证 |
| **长期（数年）找回** | 仅 62 条测试规模 + 结构化模拟；无真实用户数月使用 | ⚠️ 假设，待真人验证 |

### Persona B · AIGC Creator

**痛点假设**：生成大量图片，但风格越来越混乱——缺一个「我自己视觉方向」的锚。

| 目标 | 现有证据 | 判定 |
|---|---|---|
| 建立个人视觉方向 | 四组倾向统计（深空间/居中/低饱和/孤立人物）+ confidence 阶梯诚实（P5.8.4）；P5.7 场景 B 曾以 AIGC 创作视角验证输出格式 | ✅ 机制已验证 |
| 保留成功案例 | origin=ai-generated 是 schema 一等枚举；上传/检索/画像对 AI 生成图同样工作（P5.3.2 stress 曾覆盖） | ✅ 能力已验证 |
| **真实 AIGC 用户工作流** | 无真人 AIGC 创作者使用记录 | ⚠️ 假设 |

### Persona C · Design / Art Student

**痛点假设**：看过很多作品，但无法形成自己的视觉语言。

| 目标 | 现有证据 | 判定 |
|---|---|---|
| 学习（看懂为什么） | reasons 解释层——每条命中给出「环境压过人物 / 纵深很深」式解释，可迁移为分析语言（P5.8.3 九案例 100% 在场） | ✅ 能力已验证 |
| 分类 | 结构化视觉语言天然分组（spatial/composition/color/narrative） | ✅ 能力已验证 |
| 反思 | Profile「只统计你自己保存的」即反思工具（User B：「原来我存的图偏向低饱和」，P5.8.2 Task 5） | ✅ 机制已验证 |
| **学生真实使用** | 无学生用户记录；P5.8.3 User C（非创作者）显示价值感知最弱 | ⚠️ 假设，且预期为次级用户 |

## STEP 2 · Value Proposition Matrix

核心口径：**不是「AI 帮你找图」，而是「帮你保存和理解自己的视觉记忆」。**

| 用户 | 当前痛点 | 产品解决 | 证据 |
|---|---|---|---|
| 导演 | 参考海里找不到「为什么喜欢」；跨媒介参考无法关联 | 同一视觉语言跨媒介检索 + reasons 解释 + 个人倾向档案 | P5.9.0 Scene 3 实测；P5.7 Case A/C；P5.8.4 grounding |
| AIGC | 生成量大但风格漂移，无锚点 | 个人收藏统计 = 风格锚；成功案例按视觉关系可召回 | P5.8.4 画像阶梯；schema ai-generated 枚举 |
| 学生 | 看得多但说不出自己的视觉语言 | 收藏→视觉语言→档案的反思闭环；每条命中带可学习解释 | P5.8.2 Task 5/6 真实反馈；REASON_LABELS 解释层 |

反交叉检查（是否滑向 AI 噱头）：
- ❌ 不承诺「AI 懂审美」（禁词纪律，P5.6 起 QA 断言零出现）
- ❌ 不做推荐流/信息流（冻结边界，无 recommendation）
- ❌ 不自动创作（Assistant 尾注「最终决策在你」）
- ✅ 承诺的是：保存（local-first）+ 理解（解释层）+ 找回（by feeling）+ 反思（档案）

## STEP 3 · 使用路径验证（引用既有真实运行，不新造）

### Flow A · 新用户第一次使用
```
进入产品 → 上传 10 张 → 生成视觉语言 → 看到档案 → 寻找参考
```
**验证状态：✅ 已验证（结构化模拟口径）**。P5.8.2 三画像全流程走通：空状态文案直接对上素材直觉、上传 0 阻塞、Task 3 能复述 AI 看到什么、Task 4/5/6 依次理解检索/档案/Assistant；上传完成态已加「已转译成你的视觉语言→去哪用」引导（P5.8.2 修复后重复测试通过）。User C 在 Task 1 的「这是什么」困惑为已知残留（首页一句话说明，授权面外记录）。

### Flow B · 30 天后使用
```
继续收藏 → 形成档案 → 创作时搜索 → 获得参考
```
**验证状态：✅ 机制已验证 / ⚠️ 真实留存未验证**。P5.8.4 以「同一用户池 26→62 增长」模拟长期：confidence 自动升级（tendency→pattern）、画像漂移收敛（meanDrift ≤0.067）、Assistant 引用始终锚定个人池且补全随历史演化。30 天真实回访行为无数据。

### Flow C · 创作场景
```
输入："我要设计一个孤独旅人在荒原中的镜头"
```
**验证状态：✅ 已验证**。P5.7 Case A 完整走通（Metropolis / 雾海漫游者 / 宋代山水参考包 + 视觉关系输出而非「这个角色很孤独」）；P5.9.0 Scene 3 以真实数据复现（8 hits/2ms/为什么匹配可见）；P5.8.3 三池同查询三答案证明结果由个人收藏决定。

## 小结

- 三个 Persona 的**产品机制均有真实证据支撑**；缺口一致地落在「真人 + 长期 + 规模」三处（与 STEP 0 未验证假设表一致）。
- 第一用户信号最强的方向：**Film / AIGC 创作者**（Flow C 完整闭环 + P5.7 工作流验证 + P5.8.2/3 User A 全程最优表现）。
