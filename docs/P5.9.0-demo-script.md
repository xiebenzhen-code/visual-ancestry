## Scene 1（0:00-0:50）Image → Visual Language

**画面**：Memory 档案任选一张已存条目详情（如 `stress-a-s07`，电影剧照）。
**展示**：详情页视觉语言字段——情绪、色彩、构图、空间、人物关系。
**口播**：
> 「你存下一张图，AI 不是打标签，而是把它读成一套视觉关系——人物与环境的关系、机位与主体的距离、光的质地。这些关系跨媒介通用：一张电影剧照和一幅画，用的是同一种语言。原图只存在你本地，AI 读完后存的是这套视觉语言。」

**数据锚点**：intent 字段 arousal/atmosphere/cameraDistance/cameraHeight/colorTemperature/contrast/emotion/environmentDominance/humanRelation…（schema 全字段，冻结）。

## Scene 2（0:50-1:30）Personal Memory → 倾向，不是评价

**画面**：`#memory/profile`（我的视觉档案）。
**展示**（userA 池 62 条实测）：
- 空间：深空间 65% · 环境主导 55%
- 构图：主体居中 90% · 静止画面 85%
- 色彩：低饱和 81%
- confidence：`pattern — based on 62 visual memories`
**口播**：
> 「这是你的收藏统计，不是 AI 给你的审美打分。它只统计你自己存下的画面，与浏览记录无关。样本不足时它明确说『初步观察』，够多了才升级为『倾向』、『模式』——所有判断都有样本量。」

## Scene 3（1:30-2:20）Retrieval — 为什么匹配

**画面**：`#memory/search`（按感觉找回）。
**输入**：「孤独旅人的荒原场景」→ 结构化选择：孤立人物 + 深空间 + 环境主导。
**展示**（release 混合池 42 条实测，2ms）：
- 8 hits；top6 中**电影参考与绘画参考混合命中**：
  - `stress-a-s07`（电影剧照）score 7 —「环境压过人物 / 纵深很深」
  - `stress-b-r-ankuant`（绘画参考）score 7 —「环境压过人物 / 纵深很深」
- 每条结果下方都有 reasons：**为什么匹配可见**。
**口播**：
> 「它返回的不是相似图片，而是共享同一组视觉关系的跨媒介参考。每一条都告诉你为什么被找到——这是检索证据，不是黑盒推荐。如果档案里没有这种感觉，它诚实地说『没有找到』，绝不硬凑。」

## Scene 4（2:20-3:00）Assistant — 个人历史驱动的创作辅助

**画面**：`#memory/assistant`（Visual Assistant，三张卡，非聊天窗口）。
**输入**：「下一部作品的开场画面」→ creative_support。
**展示**（userA 池 62 条实测）：
- 四组方向：深空间 65% / 主体居中 90% / 低饱和 81% / 孤立人物 46%…
- 参考包 6 条（全部来自个人池，引用如 `ua-07` `ua-09`…）
- 尾注：「以上方向全部来自你自己的收藏统计与历史参考——不是 AI 创作，最终决策在你。」
**口播**：
> 「Assistant 不聊天、不替你创作、不打审美分。它做的三件事都来自你自己的历史：总结你的倾向、在你的收藏里找参考、把个人记忆整理成创作提示。你的档案越厚，它越懂你——数据从不离开你的浏览器。」

**总收尾字幕**：`A system that remembers how you see. — Local-first · No embedding · No recommendation · No cloud`
