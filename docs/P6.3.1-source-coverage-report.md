## 1. 关键发现：Rijks 曾被我错误地判定为「不可用」

### 第一轮：Rijks 11 个主题全部返回 0

我此前在 P6.3 报告里写「Rijks 只支持 creator 检索」。这一轮用 `subject=` 参数探测，**全部返回 0**，看起来像是「该源不支持主题搜索」。

### 诊断：分清「源不支持」与「我调错了」

两种情况导向完全相反的产品决策，所以必须分清。逐参数实测：

| 参数 | 结果 |
|---|---|
| `subject=Rembrandt` | **HTTP 400** |
| `q=` / `keyword=` / `text=` | **HTTP 400** |
| `description=landscape` | ✅ 200，total 347 |
| `title=landscape` | ✅ 200，total 1083 |
| `creator=Rembrandt` | ✅ 200，total 1447 |

**根因**：`subject=` 这个参数名根本不被接受（直接 400），而我的适配器正是用它做主题检索。正确参数是 `description=` / `title=`。

### 修正后：Rijks 10/11 主题可用

```
landscape  →  Hashimoto Kansetsu《Landscape in China》c.1930
portrait   →  Vincent Samuel Mentz 肖像 1980
night      →  Samuel Jessurun de Vries 1917
interior   →  「Schaal en een kop en schotel」c.1750
sea        →  「The bodhisattva Maitreya」c.200-300
crowd      →  Hans Holbein(II)《Skeletons Making Music》1524-1526
city       →  Wouter Johannes van der(Hgg)《De Raampoortje in Amsterdam》1809
```

**Rijks 的馆藏结构与另两家明显不同** —— 包含版画、器物、雕塑、摄影，不只是绘画。这对「换一个视觉需求」是**优势而非缺陷**。

> 这是本阶段发现的**第三个 Rijks 缺陷**（前两个：IIIF 路径 404、`isShownBy` 在顶层而非 `aggregatedCHO`）。三个都是适配器问题，源本身完全健康。

## 6. `asian-art` 主题的核验结果：关键词命中 ≠ 类别正确

上一轮我把这个主题标为「三源都返回 3 张，未逐张核实」。这一轮用**博物馆自己的结构化字段**（department / culture / classification）逐条核验，结论是**该主题标签不可信**。

### 6.1 逐源核验

| 源 | 真亚洲艺术 | 具体判定 |
|---|---|---|
| **Met** | **2/6** | ✗《Asian》by Höchst Manufactory → **European Sculpture and Decorative Arts**（欧洲瓷器厂的中国风）<br>✗《Figure of an Asian man》→ 同上<br>✗《Wall Tile Depicting an Asian Captive》→ **Egyptian Art**（埃及艺术部）<br>✗《Asian King from an Adoration Group》→ **The Cloisters**（中世纪欧洲艺术部）<br>✓《Sketches of East Asian Legendary Figures》→ **Asian Art**<br>✓《Head of a Central Asian Figure》→ **Islamic Art** |

**Rijks 最差** —— 搜「Asian」返回的是「银壶与瓷器的静物画」「盘子上的花」。它的 subject 索引里 `Asian` 几乎不作为规范词使用。

### 6.2 修正后的结论

```
asian-art 主题的真实可用率：6/18 = 33%
其中 Met 2 · AIC 3 · Rijks 1
```

**三源并用能拿到亚洲艺术，但必须用 department/culture 字段过滤，不能靠标题或自由文本搜索。**

**这与 P6.3.1 剧照审计是同一类错误的第四次复现**：
1. 剧照：搜电影名 → 返回玩具/教堂（关键词 ≠ 类别）
2. 绘画：`997 张里 51 个叫 landscape`（sha 唯一 ≠ 语义唯一）
3. 平衡集：`Black pirate poster.jpg` 被当彩色片画面（真实图片 ≠ 电影画面）
4. ** asian-art：搜「Asian」→ 返回法国巴比松橡树林版画（关键词 ≠ 传统）**

> **每一次都是同一句话的变体：我在验证「某个维度」，却在报告「另一个维度」。**

### 6.3 正确的做法（已实现）

```js
// 不看标题，只看博物馆自己的归类字段
const isAsian = ASIAN_DEPARTMENT.test(department)      // "Asian Art" / "Islamic Art"
              || ASIAN_CULTURE.test(culture)            // "India" / "Japan" / "China"
              || ASIAN_CLASSIFICATION.test(classification);
```

`work/p6.3.1c/verify-asian-art.mjs` 已实现并产出 `asian-art-verification.json`。

**产品含义**：若要支持「找东亚艺术」这类查询，应该**查询 department 字段**（如 Met 的 `department=Asian Art`），而不是全文搜 `Asian`。这是一个可直接落地的产品改进点。
