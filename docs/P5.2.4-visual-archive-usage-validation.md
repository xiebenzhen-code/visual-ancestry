# P5.2.4 — Visual Archive V1 Usage Validation（产品判断报告）

Date: 2026-10-02 · 验证阶段 · V1 全程冻结 · **零代码修改**（仅报告/数据/一次性工具）

**Personal Visual Archive V1 通过了使用验证：它不是 AI 标签工具，而是视觉记忆系统的一个真实 V1；值得进入 P5.3，但 P5.3 必须诚实处理氛围/情绪层的稀疏性。**

## 问题一：它是不是 AI 标签工具？

**不是。** 三个证据：

1. **输出是视觉语言，不是标签**（STEP 2/3）：上传零手动标签、自动转译出 25 字段结构化意图（空间纵深/环境主导/人物尺度/光质/色彩温度/人际疏离…）。标签工具输出「类别」（夜景/城市/人物），这里输出**构图与关系**（「人物尺度很小 + 环境压过人物 + 留白很大」）。
2. **语言直接驱动检索**（STEP 4）：标签止于分类，这里同一语言空间既是收藏的转译、又是查询的输入、又是匹配的理由（`retrievalCard` 展示「✓ 环境压过人物 / 纵深很深 / 留白很大」）——语言被**使用**，而非展示。
3. **诚实的边界**：转译确有质量缺陷（emotion 15 张仅 2 张非空、夜莺的「夜晚」漏抓、composition/geometry 全空），但这是**质量缺陷**不是性质问题。若有一天只靠氛围词查询且频繁落空，才会退化为标签工具——当前结构层检索可靠（见问题二），不成立。

## 问题二：它有没有成为视觉记忆系统？

**是，核心行为已成立。** 证据链：

1. **收藏**：连续添加 20 张，终态 19/20 成功（95%），失败可见可重试（P5.1.8 契约）——收集摩擦可控（`upload-validation.json`）。
2. **按感觉召回**（STEP 4）：
   - Case 1「孤独荒凉大空间」→ 波将金号/范宽/漫游者/千里江山/卡里加里（13.1–10.6）✅
   - Case 3「巨大环境小人物」→ 增上寺雪/马远独钓 top2（10.0）——**马远与川濑巴水并列，跨 800 年东西方、跨画作/版画** ✅
   - Case 5「环境压过人物」→ 5 条全中（11.0）✅
   - Case 2「旧工业城市冷色夜晚」→ 部分（夜晚 token 池内仅 2 条，工业不可表达）——**检索诚实反映池子，不假装命中**
   - Case 4「手工模型童话孤独」→ 诚实降级为可映射子集（低饱和+雾+孤立）——**系统不虚构它不懂的语义**
3. **解释**：每条返回都带中文理由（evidence），用户知道**为什么**是这条，而不是黑箱推荐。
4. **对照实验**（STEP 5）：方法 A（文件夹 电影/夜景/城市/参考）找「孤独低饱和深空间」需回忆文件夹 → 打开 1–2 处 → 逐张目测（~2s×20 = 40s+）→ 跨分类同类（波将金号在电影、范宽在画作）必须遍历两处且靠眼力；方法 B 实测 **0–3ms** 召回 top5 + 理由，跨 film/art 自动归并。

**诚实限制**（记录不改）：池内同质化时区分度有限（多张山水同为环境主导）；氛围词稀缺使「夜晚/热闹」类查询弱召回；emotion 层几乎空转（STEP 3 已证）。记忆系统的「记忆」目前强在结构、弱在情绪。

## 问题三：是否值得进入 P5.3 Personal Visual Profile？

**值得，且前提已由本阶段验证。** P5.3 的定义（V1 路线图）= 个人池 visualIntent 聚合 → 审美画像「我的审美是什么」。

- **本阶段提供了聚合的必要前提**：STEP 3/4 证明转译在**结构层稳定且跨作品产生语言共性**（马远/增上寺/波将金号共享「巨大环境小人物」；范宽/漫游者/千里江山共享「环境压过人物+空旷」）——若转译是噪声，聚合无意义；现在聚合有真实信号。
- **P5.3 的边界建议**：只聚合 V1 已产出的稳定结构字段（spatialDepth / environmentDominance / subjectScale / humanRelation / negativeSpace / socialDistance / saturation / colorTemperature…），对 atmosphere/emotion 的稀疏性**诚实标注**（如「该用户的情绪层样本不足，画像仅覆盖空间与色彩倾向」），不因画像而优化模型——优化模型属冻结层变更，需显式授权，是另一决策。

## Next Decision

**进入 P5.3 Personal Visual Profile（聚合层）**，边界：
1. 只读聚合 V1 冻结 `visualIntent`，不碰模型/权重/schema；
2. 输出个人审美画像（结构倾向 + 稀疏性诚实标注）；
3. 若 P5.3 暴露氛围/情绪层问题（如画像因 emotion 空转而无意义），**单独立项**评估是否解锁冻结层改进 emotion 可靠性——不得夹带在画像阶段。
