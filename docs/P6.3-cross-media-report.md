## 3. 对照实验：失败归因（关键方法论）

### 3.1 实验设计

4 个未达标的查询全部含 `colorTemperature:"cool"` 或 `subjectScale:"small"`。这两个字段有个共同点：**博物馆元数据推不出来**（"Oil on canvas" 不含冷调信息）。

**假设**：跨媒介失败不是检索核的问题，而是 rule-fallback intent 的表达能力问题。

**验证方法**：统计每个池里，**各媒介分别有多少条目能表达这两个字段**，再重跑同样的查询。

### 3.2 实测结果

| 池 | 池构成 | `cool` 可用量（按媒介） | `small` 可用量（按媒介） | 跨媒介 |
|---|---|---|---|---|
| artFilm | 绘画 62 / 摄影 5 / 电影 5 | painting **10** / photo 0 / film **0** | painting **25** / photo 0 / film **0** | 0/4 |
| filmArt | 电影 30 / 摄影 5 / 绘画 40 | painting **1** / film **0** | painting **25** / film **0** | 2/4 |
| mixed | 电影 18 / 绘画 48 | painting **4** / film **0** | painting **22** / film **0** | 3/4 |

### 3.3 结论：**归因确定**

```
film 池的 cool 可用量恒为 0，small 可用量恒为 0
painting 池才有这些值
```

查询要求 `cool` 时，**只有绘画能满足**，所以只返回绘画——**这是数据事实，不是产品缺陷**。

**决定性对照**：mixed 池的 c1/c2/c3 **跨媒介成功**了。同样的查询、同样的检索核、同样混合的池，只因为那几帧默片的 vision intent 恰好命中了 `cool`，跨媒介就成立了。**这证明统一空间本身是通的。**

## 4. 为什么这条限制必须诚实归因于 vision 凭据

如果用真实 vision intent 处理这100 张外部画作（凭据到位后），会发生两件事：

1. **画作会正确表达冷暖色调**（Vision 层真的看到画面），届时 `cool` 在绘画和电影两侧都可用
2. **误召回会消失**（P6.3 STEP 2 记录的 Still Life 被「巨大环境」召回，正是因为规则只读文本关键词）

因此 4 个失败应当读作：**「无 vision 凭据时的预期降级」，不是「统一空间失败」**。
