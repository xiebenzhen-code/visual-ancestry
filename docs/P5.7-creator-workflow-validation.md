# P5.7 — Creator Workflow Validation

> 验证 Personal Visual Assistant 是否真的进入创作者工作流，而不是停留在「好看的 Demo」。
> 本阶段零产品代码改动、零冻结面触碰——只有薄层调用、测试数据、案例记录。

---

## Problem

创作者的日常不是「搜一张类似的图」，而是一连串具体的创作动作：

- 收集了上千张参考，**但无法重新调用**——想要「孤独的人在荒原」时，翻不到三年前存的那张宋代山水
- 角色设计时凭印象说「这个角色很孤独」，**说不出自己的视觉语言**是什么
- 开新项目（视觉 Bible）时，积累的审美经验**完全不在场**

工具解决「存放」，不解决「创作时刻的调用」。

## Solution

Personal Visual Assistant —— **Remember how you see.**

三个创作任务直接接入个人视觉记忆：理解我的偏好（Profile 统计）、寻找我的参考（冻结检索 + 为什么匹配）、辅助我的创作（个人记忆的结构化 Brief）。没有聊天窗口、没有生成式创作、没有审美评价——每一个输出都来自用户自己保存的资产。

## Evidence

三个真实创作场景，全部在 34 条真实资产池上运行（`work/p5.7-workflow/case-*.json`，含完整输入→检索→证据→画像→决策留白记录）：

### 1. 场景设计（Case A）

**输入**：「我要设计一个荒原夜晚镜头。要求：孤独、巨大空间、人物渺小、工业废墟感」

**Assistant 完成**：需求 → VisualQuery（孤独→isolated、荒原→留白+空旷、夜晚→氛围 token）→ 检索个人资产 → 解释匹配原因 → 视觉参考包：

> Die Nibelungen 1924（电影）· 印象·日出 · 马远·独钓 · 雾海漫游者 · 神奈川冲浪里 · 广重·骤雨（绘画）——每条带「环境压过人物 / 纵深很深 / 留白很大 / 氛围·寂静」理由

**诚实细节**：「人物渺小/工业废墟感」被明示为未映射（不假装理解）；**Metropolis 未被塞入参考包**——它是群像构图，与「孤独」语言不符，系统拒绝凑数。

### 2. 角色设计（Case B）

**输入**：「我要设计一个长期独行的人物。」

**输出不是**「这个角色很孤独」，**而是**：

> 你的收藏中存在：大环境压迫人物（19/34 · 56%）、深空间（71%）、低饱和（76%）、孤立人物（47%）、静谧低唤醒（53%）——共同视觉语言：小主体 / 大环境 / 低饱和冷调观察

远景镜头 29% 低于 40% 主张门槛，被纪律性隐藏——系统只说数据支持的话。

### 3. 项目视觉 Bible（Case C）

**输入**：「总结我的视觉倾向，用于下一部短片。」

**输出**：样本 34 assets · confidence tendency · 主要出现——空间：深空间 71%；色彩：低饱和 76%；关系：环境主导 56%；常见视觉结构：主体居中 88% / 静止画面 74%。零评价词（无「审美高级/风格独特/适合拍XX」——QA 断言固定）。

### 跨项目验证（STEP 3）

「设计《未送达的消息》的荒原」→ **Film（Die Nibelungen）+ Painting（5 幅）进入同一视觉语言空间**。Personal AIGC 诚实缺席——C 类资产不在验证池（P5.3.2 素材源限制），未伪造。

## Workflow Trail

```
创作需求 → Assistant → 个人视觉资产 → 视觉参考包 → 创作者决策
   ✅         ✅            ✅(34 pool)      ✅(带证据)      ◯ 按设计留白
```

每条记录（`work/p5.7-workflow/case-*.json`）含 `{input, retrieved, evidence, profile_used, human_decision}`——决策环节是留白的输入框，不是伪造的「AI 替你选好了」。

## Limitations

- **Local-first**：数据只在本地，无账号无云同步
- **单用户**：多用户/协作场景未覆盖
- **非自动导演**：Assistant 只整理个人记忆，不生成导演方案、不替用户决策——决策留白是架构而非缺陷
- **非替代创作者判断**：统计倾向是「你收藏了什么」的描述，不是「你该拍什么」的规定
- **规则式理解**：长尾表达（独行/粉色/工业废墟感）明示未映射——不假装理解是刻意的诚实设计
- **Personal AIGC 缺席**：验证池无 C 类 AIGC 资产（外部素材源限制），跨媒介验证覆盖 Film+Painting
- 「启发」指标需真实创作者填写（`work/p5.7-workflow/human-evaluation-checklist.md` 人工评分栏留白）
