- **MOCK / 回放**：本轮完整重排测试使用注入桩；首页分析链复用 P4.2 响应。不得将回放次数累计为真实模型调用次数。
- **已验证功能**：本轮复验 #find 路由、本地搜索结果、上传预览/移除、回放进入检索、真实 scoring 驱动的可选重排和降级闸门。CREATE/SHOOT/MEMORY 等能力沿用既有验收范围，本轮未全量重测。
- **未验证艺术推荐能力**：没有独立人工标注集上的 Top 5 相关性、成对排序正确率或 AUC 改善证据；像素描述子效度失败，视觉嵌入未在本轮引入。不得宣称“视觉相似搜索完成”。

## 恢复方式

备份分支计划名：`backup/p4-vision-verified-20261019`。这份提交内文档不预先宣称远端上传成功；以交付回执中核验的远端 SHA 为准。不创建额外标签或移动旧标签。

在干净工作区恢复该备份，保留原有分支：

```powershell
git fetch origin backup/p4-vision-verified-20261019
git switch -c restore/p4-vision-20261019 --track origin/backup/p4-vision-verified-20261019
```

若需回到原 P4.10 产品代码，另开恢复分支：

```powershell
git switch -c restore/p410-original 119e229e48a1c962c3abee63e306f728b8240857
```

执行前先 `git status`；若有未提交工作，先保存，禁止用 `reset --hard` 或强制推送覆盖。以上操作不修改远端 main 或发布标签。
