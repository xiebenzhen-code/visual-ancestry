## Product Position

**当前产品是什么**

Visual Archive（V2 Alpha）——一个 **local-first 的个人视觉记忆系统**，面向创作者：

```
Image → Visual Language → Personal Memory → Retrieval → Visual Profile
```

不是图片管理工具（Eagle/Pinterest 解决「存放」），而是解决「记忆」：把每一次收藏转译成 25 字段的结构化视觉语言（空间纵深/环境主导/光质/人际疏离…），让收藏可按感觉检索、可解释、可反思。三核心能力全部实测：

1. **Visual Translation**——图片→视觉语言，零手动标签
2. **Visual Retrieval**——按感觉找回 + 「为什么匹配」中文理由
3. **Visual Profile**——收藏→统计→样本量绑定置信级的倾向画像

## Core Problem

**解决什么问题**

> Reference accumulation ≠ visual memory.

创作者积累几千张参考，但文件夹只记得文件、不记得视觉关系：找回靠翻找、参考之间无联系（宋代山水与 1927 年电影远景共享同一构图却被隔开）、收藏从不产生认知（存了 1000 张说不出自己偏好什么）。签名能力是**跨媒介视觉语言命中**——「孤独 + 巨大环境 + 低饱和」同时召回电影布景与北宋山水/浪漫主义绘画，因为它们被同一种语言描述。

## Remaining Limitations

**诚实限制**（必须原样进入 Release 页面，不作淡化）

1. **Local-first / Single user**——数据只在本地，无账号无云同步（隐私优先，也是边界）
2. **40 assets validated（100 not completed）**——外部素材源限制（Commons 429 + AIGC 服务不可达），非产品缺陷；33 张池上趋势已稳定
3. **Emotion field limitation**——情绪词产出稀疏（冻结 Vision 层已知问题），叙事组由结构字段承载
4. **Cross Media Partial PASS**——showcase 3 主题仅 1 项跨媒介 READY（池构成限制，如实记录）
5. 检索是结构化选择，无自然语言解析（刻意的第一版决策）；部分创作语义 token 空间不可完整表达
