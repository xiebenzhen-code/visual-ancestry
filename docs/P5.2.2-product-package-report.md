## Product Definition

**Personal Visual Archive**（个人视觉档案）——把用户在意画面变成"可被视觉语言找回"的个人资产库：

```
图片 → Vision → VisualIntent → VisualMemory → Personal Retrieval
  上传        转译         沉淀         可浏览       按感觉找回
```

- 不是 AI 标签工具：每一张图转译成同一种视觉语言，检索的依据是视觉语言本身（不是文件名/标签/文件夹）
- 不是搜索系统：是"按感觉寻找"——用户描述记得的画面感觉，档案用同一种语言回应，并展示**为什么匹配**

## User Flow

```
进入 Archive（#memory，首页）
  ↓  ＋ 保存一段新素材（或拖入多张）
上传（#memory/upload，批量 + 实时进度 + 失败可重试）
  ↓  AI 逐张转译成视觉语言
生成视觉档案（成功卡片 / 失败卡片）
  ↓  浏览收藏（#memory，图片 + 视觉关键词 + 失败计数）
输入视觉需求（#memory/search，结构化选择：氛围/空间/色彩/人物）
  ↓
找回参考（retrieveVisualMemory 薄层，返回 top-8）
  ↓
查看为什么匹配（retrievalCard：✓ 匹配原因 + 字段证据 + 匹配度）
```

三个页面：**Archive 首页（已有，加入口） / Upload（保持现有） / Search（新增）**。

## Implemented Features

### STEP 0 — Boundary Audit（只读，`docs/P5.2.2-boundary-audit.md`）
确认已有能力（上传/Vision/保存/浏览/删除/Retrieval 服务层）；缺失 = 用户入口 + 查询入口 + 匹配解释展示 + 完整流程；`retrieveVisualMemory` 此前**无任何 UI 调用**。命名冲突确认：`#search` 被全局搜索层占用 → 新路由用 `#memory/search`。

### STEP 1 — 流程设计
唯一核心流程 = 上传 → 转译 → 浏览 → 按感觉寻找 → 找回 → 为什么匹配。第一版**结构化选择**（不引入 NLP）。

### STEP 2 — 检索页（新增 `src/pages/memorySearch.js`）
- 结构化选择中文 UI → schema token（氛围多选：寂静/空旷/夜晚/雾/热闹/阴郁；空间/色彩/饱和度/人物单选）
- 只调用 `retrieveVisualMemory()` 消费结果——**零复制 score/filter/ranking**
- 诚实空态：「没有找到接近的感觉…换个条件试试」，不强行推荐

### STEP 3 — 结果卡片（新增 `src/components/memory/retrievalCard.js`）
- 图片 + 标题 + **「为什么匹配」原因列表（✓ 氛围 · 寂静 / 纵深很深…）** + 字段证据标签 + 匹配度
- 纯工具语言，**无「AI认为/模型觉得」**；matchedFields 字段名→中文仅展示映射（不参与检索）

### STEP 4 — 产品视觉整理（`src/styles/memory.css` 追加 + `src/pages/memory.js` 首页）
- 首页双 CTA：保存素材 + **「按感觉寻找 →」**；计数行「已保存 N 段视觉记忆 · X 条分析失败，可重新分析」
- Search 构建器（chips 选择态/清除条件/找回按钮）+ 结果网格 + 位置：定位"按感觉寻找"而非搜索引擎

## Known Limits

1. **浏览器 DOM 点击级验证受限**（环境 Chromium 不可用，P5.1.5 起已声明）：search 页交互（chips 选择/找回/结果渲染）未经真实浏览器点击验证——由构建产物 + Node 端流程 QA（Case1-4 语义等价）覆盖
2. **查询仅结构化**：无自然语言输入（范围决策，P5.2.1 起明确）；用户需先理解"氛围/空间/色彩"这类视觉语言
3. **并列分数/池内同质化**：isolated/deep/低饱和高频 → top 内区分度有限（P5.2.1 已记录）
4. **真实产品数据不可达**：用户在浏览器 localStorage 的收藏本环境不可读；验证/Demo 用隔离回测池（真实 provider 结果，语义等价）
5. **无多用户/云同步/向量库**：禁制事项确认未做——当前核心问题不是规模，是"用户是否会通过视觉语言再次调用自己的资产"
